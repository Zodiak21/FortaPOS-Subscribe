Proteksi Enkripsi End-to-End

Standar Keamanan Militer AES-GCM 256-bit

Aplikasi ini dilengkapi Enkripsi End-to-End (E2E) tingkat perbankan menggunakan algoritma AES-GCM 256-bit yang dipadukan dengan PBKDF2 Key Derivation (100.000 iterasi SHA-256) berbasis Store ID rahasia Anda.

Algoritma Cipher: AES-GCM 256-Bit Authenticated
Key Derivation: PBKDF2 (HMAC-SHA256, 100K Rnds)
Integritas Data: SHA-256 Cryptographic Digest
Status Transmisi: Aman Terenkripsi Penuh
